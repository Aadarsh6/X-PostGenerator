# 🚀 XCraft

> AI-powered platform for generating engaging X (Twitter) posts and threads.

XCraft is a full-stack AI application that helps creators, founders, developers, and marketers transform simple ideas into engaging X (Twitter) posts and threads. By combining prompt engineering with modern web technologies, XCraft generates content that feels natural, concise, and optimized for social media.

---

## ✨ Features

- 🤖 AI-powered X/Twitter post generation
- 🧵 Generate both single posts and multi-post threads
- 🎯 Prompt-engineered prompts for high-quality output
- 💾 Save generated posts
- 📋 One-click copy to clipboard
- ⚡ Fast and responsive user interface
- 🌙 Clean and modern design
- 🔒 Secure backend API

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Aadarsh6/X-PostGenerator.git

cd X-PostGenerator
```

### Install dependencies

Frontend

```bash
npm install
```

Backend

```bash
npm install
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the backend.

```env
PORT=3001

DATABASE_URL=your_database_url

GROQ_API_KEY=your_api_key
```

---

## ▶️ Running the Project

Frontend

```bash
npm run dev
```

Backend

```bash
npm run dev
```

## 💡 Why I Built XCraft

Creating engaging content on X consistently is difficult. Even when people have good ideas, turning those ideas into concise, engaging posts often takes time.

XCraft was built to remove that friction. It leverages AI and carefully engineered prompts to help users generate high-quality content while keeping complete control over their ideas and writing style.
